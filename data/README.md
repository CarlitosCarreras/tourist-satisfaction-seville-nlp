# Data

This folder contains the anonymized dataset used in the project **Tourist Satisfaction Analysis in Seville Using NLP**.

The dataset was created from publicly available reviews collected from TripAdvisor and Civitatis using the Web Scraper browser extension.

To protect user privacy, personally identifiable information and profile-related fields were removed from the original dataset prior to publication.

## Dataset Description

The dataset includes:

- Tourist destination
- Review source
- Publication date
- Review title
- Review text
- Travel date
- Travel type
- Country of origin
- Resident or foreign visitor classification
- Spanish autonomous community (when available)

## Data Collection

Reviews were collected from publicly accessible webpages between 2024 and 2025 using automated web scraping techniques.

The data were subsequently cleaned, standardized, and prepared for Natural Language Processing (NLP) and sentiment analysis.

## Anonymization

The published version of the dataset excludes:

- User names
- Other information that could directly identify individual reviewers

## Intended Use

This dataset is provided exclusively for:

- Educational purposes
- Academic research
- Portfolio demonstration
- Reproducibility of the analyses contained in this repository
